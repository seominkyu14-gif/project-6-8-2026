현재 연결 상태: Firebase 연결 중… · 필요한 설정 키: apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId

연결 진단 · SDK 로드: 진행 중 → 앱 초기화: 대기 → 익명 인증: 대기 → Firestore listener: 대기 → 방 문서 읽기/쓰기: 대기

방 만들기·PIN 참가·게임 내부 버튼은 Cloud Firestore를 사용합니다. ‘데모로 시작하기’·‘데모 참가하기’는 데모 전용이며, DEMO01은 데모 방입니다.

  1. Firebase 프로젝트를 생성합니다.
  2. 웹 앱을 등록하고 공개 웹 설정값을 확인합니다.
  3. Cloud Firestore 데이터베이스를 활성화합니다.
  4. Authentication에서 익명 로그인을 활성화합니다.
  5. 웹 앱 설정값이 적용되어 있습니다. 익명 로그인과 Firestore 보안 규칙을 확인하세요.
  6. Firestore 보안 규칙을 설정합니다.
  7. 여러 기기에서 같은 PIN으로 테스트합니다.

개발용 예시 · 운영용 아님 다음 규칙은 인증된 사용자에게만 접근을 허용하지만 방별 권한을 제한하지 않습니다. 실제 운영 환경에 그대로 배포하지 마세요.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

운영용 보안 강화 발표자 권한을 검증하고 학생은 본인의 참가 정보와 선택만 수정하도록 제한하세요. roomId별 접근과 PIN 조회를 제한하고, 서버 측에서 결과·점수를 검증하며 방 만료 정책을 적용하세요. 개발용 규칙만으로는 클라이언트 점수 조작을 방지할 수 없습니다. 서비스 계정 키와 관리자 비밀값은 브라우저에 넣지 마세요.
